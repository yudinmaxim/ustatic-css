# Class Dictionary

## 📐 Align

| Class | Description |
|-------|-------------|
| `.align-baseline` | Align to baseline |
| `.align-top` | Align to top |
| `.align-middle` | Align to middle |

## 🎬 Animations

| Class | Description |
|-------|-------------|
| `.blink` | Blinking |
| `.animation:spin-1` … `.animation:spin-10` | Spinning |
| `.active:pulse` | Pulse on click |

## 🎨 Bg

| Class | Description |
|-------|-------------|
| `.bg-{color}` | Background color |
| `.bg-opacity-{0\|25\|50\|75\|100}` | Background opacity |

## 🖼️ Border

| Class | Description |
|-------|-------------|
| `.border` | 1px border |
| `.rounded-base` | Base rounding |
| `.rounded-full` | Full rounding |

## 📐 Flexbox

| Class | Description |
|-------|-------------|
| `.flex` | Flex container |
| `.flex-column` | Vertical direction |
| `.items-center` | Center items |
| `.justify-between` | Space between |

## 📏 Sizing

| Class | Description |
|-------|-------------|
| `.w-{size}` | Width |
| `.h-{size}` | Height |

## 🔤 Typography

| Class | Description |
|-------|-------------|
| `.text-{size}` | Text size |
| `.font-{weight}` | Font weight |
| `.text-{color}` | Text color |
