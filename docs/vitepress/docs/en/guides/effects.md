# Effects

Classes for opacity and rotation.

## Opacity

| Class | Description |
|-------|-------------|
| `.opacity-0` | Fully transparent |
| `.opacity-50` | 50% opacity |
| `.opacity-100` | Fully opaque |

## Rotate

| Class | Description |
|-------|-------------|
| `.rotate-0` | No rotation |
| `.rotate-45` | Rotate 45° |
| `.rotate-90` | Rotate 90° |
| `.rotate-180` | Rotate 180° |
