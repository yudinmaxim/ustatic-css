# Border

Classes for managing borders and rounded corners.

## Border Width

| Class | Description |
|-------|-------------|
| `.border-0` | No border |
| `.border` | 1px border |
| `.border-2` | 2px border |

## Border Radius

| Class | Description |
|-------|-------------|
| `.rounded-none` | No rounding |
| `.rounded-sm` | Small rounding |
| `.rounded-base` | Base rounding |
| `.rounded-lg` | Large rounding |
| `.rounded-full` | Full rounding |
