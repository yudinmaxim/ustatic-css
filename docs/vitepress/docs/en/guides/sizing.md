# Sizing

## Width

| Class | Description |
|-------|-------------|
| `.w-full` | 100% width |
| `.w-screen` | 100vw |
| `.w-auto` | Auto width |

## Height

| Class | Description |
|-------|-------------|
| `.h-full` | 100% height |
| `.h-screen` | 100vh |
| `.h-auto` | Auto height |
