CSS filter utilities. This module is small: grayscale and filter reset.

## Available classes

| Class | Description |
|-------|-------------|
| `.grayscale` | Full grayscale (`filter: grayscale(100%)`) |
| `.grayscale-0` | No grayscale (`filter: grayscale(0%)`) |
| `.no-filter` | Reset all filters (`filter: none`) |
