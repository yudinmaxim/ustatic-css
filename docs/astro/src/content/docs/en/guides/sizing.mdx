Classes for managing element sizes.

## Width

| Class | Description |
|-------|-------------|
| `.w-full` | 100% width |
| `.w-screen` | 100% screen width |
| `.w-auto` | Auto width |

## Height

| Class | Description |
|-------|-------------|
| `.h-full` | 100% height |
| `.h-screen` | 100% screen height |
| `.h-auto` | Auto height |
