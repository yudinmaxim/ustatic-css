Classes for managing grid layouts.

## Container

| Class | Description |
|-------|-------------|
| `.grid` | Enables grid |

## Columns

| Class | Description |
|-------|-------------|
| `.grid-columns--1fr-1fr` | Two equal columns |
| `.grid-columns--1fr-2fr` | Columns 1:2 |
| `.grid-columns--1fr-3fr` | Columns 1:3 |
| `.grid-columns--2fr-1fr` | Columns 2:1 |
| `.grid-columns--3-32` | Fixed columns |
