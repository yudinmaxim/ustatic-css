Text utilities.

## Sizes

| Class | Description |
|-------|-------------|
| `.text-2xs` | 10px |
| `.text-xs` | 12px |
| `.text-sm` | 14px |
| `.text-base` | 16px |
| `.text-lg` | 18px |
| `.text-xl` | 20px |
| `.text-2xl` | 24px |

## Weight

| Class | Description |
|-------|-------------|
| `.font-thin` … `.font-black` | Weights 100–900 |
| `.font-normal` | Regular (400) — **not** `font-normal` |

## Text color

`.text-{color}`, `.text-{color}-{brightness}` — e.g. `.text-gray-600`, `.text-blue-500`.
