# Установка

## Требования

- Node.js 18+
- npm, pnpm или yarn

## Установка

<Tabs>
  <TabItem label="npm">
  ```bash
  npm install ustatic-css
  ```
  </TabItem>
  <TabItem label="pnpm">
  ```bash
  pnpm add ustatic-css
  ```
  </TabItem>
  <TabItem label="yarn">
  ```bash
  yarn add ustatic-css
  ```
  </TabItem>
</Tabs>

## Подключение в проекте

<Tabs>
  <TabItem label="ESM">
  ```javascript
  import 'ustatic-css';
  ```
  </TabItem>
  <TabItem label="CJS">
  ```javascript
  require('ustatic-css');
  ```
  </TabItem>
</Tabs>

## Использование с фреймворками

<Tabs>
  <TabItem label="Vue 3">
  Добавьте плагин в `main.js`:

```javascript
import { createApp } from "vue";
import { ustaticCss } from "ustatic-css/scripts";
import App from "./App.vue";

const app = createApp(App);
app.use(ustaticCss);
app.mount("#app");
```

  </TabItem>
  <TabItem label="React / Svelte / Vanilla JS">
  Используйте функцию `loadStyles`:

```javascript
import { loadStyles } from "ustatic-css/scripts";

// Загрузка нужных модулей
await loadStyles({ modules: ["flexbox", "spacing", "typography"] });
```

  </TabItem>
</Tabs>
