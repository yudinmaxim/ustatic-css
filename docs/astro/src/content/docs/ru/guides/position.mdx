Классы для позиционирования и z-index.

## Тип позиционирования

| Класс | Описание |
|-------|----------|
| `.relative` | Относительное |
| `.absolute` | Абсолютное |
| `.fixed` | Фиксированное |
| `.absolute-center` | Центрирование через `translate(-50%, -50%)` |

## Координаты

`.top-{key}`, `.right-{key}`, `.bottom-{key}`, `.left-{key}` — ключи из шкалы spacing (`0`, `1`, `2`, `4`, `auto`, `full` и др.).

## Z-index

| Класс | Описание |
|-------|----------|
| `.z-0`, `.z-10`, … `.z-100` | Линейная шкала (шаг 10) |
| `.-z-10`, … `.-z-100` | Отрицательные |
| `.z-i-modal` | Модальное окно |
| `.z-i-menu` | Меню |
| `.z-i-notice` | Уведомления |
