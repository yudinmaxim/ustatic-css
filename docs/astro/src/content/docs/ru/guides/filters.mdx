Классы для CSS-фильтров. Модуль небольшой: оттенки серого и сброс фильтра.

## Доступные классы

| Класс | Описание |
|-------|----------|
| `.grayscale` | Полностью чёрно-белый (`filter: grayscale(100%)`) |
| `.grayscale-0` | Без оттенка серого (`filter: grayscale(0%)`) |
| `.no-filter` | Сброс всех фильтров (`filter: none`) |
