Стилизация полос прокрутки. **Не путать с overflow** — классы `overflow-*` описаны в [Отображение (Display)](/ru/guides/display).

## Доступные классы

| Класс | Описание |
|-------|----------|
| `.z-scroll` | Базовая стилизация скроллбара |
| `.z-scroll--thin` | Тонкий скроллбар |
| `.z-scroll--hovered` | Увеличенная ширина при наведении |

Комбинируйте с `overflow-auto` или `overflow-y-auto` из модуля display.
