Классы для текста.

## Размеры

| Класс | Описание |
|-------|----------|
| `.text-2xs` | 10px |
| `.text-xs` | 12px |
| `.text-sm` | 14px |
| `.text-base` | 16px |
| `.text-lg` | 18px |
| `.text-xl` | 20px |
| `.text-2xl` | 24px |

## Начертание

| Класс | Описание |
|-------|----------|
| `.font-thin` … `.font-black` | Вес 100–900 |
| `.font-normal` | Обычный (400) — **не** `font-normal` |

## Цвет текста

`.text-{color}`, `.text-{color}-{brightness}` — например `.text-gray-600`, `.text-blue-500`.
