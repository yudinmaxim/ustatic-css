Классы для управления grid-сетками.

## Контейнер

| Класс | Описание |
|-------|----------|
| `.grid` | Включает grid |

## Колонки

| Класс | Описание |
|-------|----------|
| `.grid-columns--1fr-1fr` | Две равные колонки |
| `.grid-columns--1fr-2fr` | Колонки 1:2 |
| `.grid-columns--1fr-3fr` | Колонки 1:3 |
| `.grid-columns--2fr-1fr` | Колонки 2:1 |
| `.grid-columns--3-32` | Фиксированные колонки |
