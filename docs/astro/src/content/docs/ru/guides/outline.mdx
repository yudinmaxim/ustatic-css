Классы для контура элементов — в основном для фокуса и доступности.

## Ширина

| Класс | Описание |
|-------|----------|
| `.outline-none` | Без контура |
| `.outline-0d5` … `.outline-9` | Толщина контура (из шкалы sizing) |

## Цвет

Цвета палитры: `.outline-primary`, `.outline-blue-300`, `.outline-gray-500` и т.д.

## Стиль

| Класс | Описание |
|-------|----------|
| `.outline-style--solid` | Сплошной |
| `.outline-style--dashed` | Пунктир |
| `.outline-style--dotted` | Точки |

## Смещение

`.outline-offset-1` … `.outline-offset-10`, отрицательные: `.-outline-offset-1` и т.д.
