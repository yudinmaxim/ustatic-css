# Префикс CSS переменных (_ustatic-prefix.scss)

Файл содержит определение префикса для всех CSS переменных uStatic CSS.

## Переменная

```scss
$prefix: "u-";
```

## Назначение

Префикс используется для формирования имён CSS переменных во всей библиотеке:

| Токен | CSS переменная |
|-------|----------------|
| `base.color.primary` | `--u-base-color-primary` |
| `base.size.4` | `--u-base-size-4` |
| `base.border.radius.md` | `--u-base-border-radius-md` |

## Зачем нужен префикс?

1. **Изоляция** — предотвращает конфликты с другими CSS библиотеками или пользовательскими переменными
2. **Идентификация** — легко определить, что переменная принадлежит uStatic CSS
3. **Кастомизация** — можно изменить префикс в проекте при необходимости

## Изменение префикса

Если нужно изменить префикс, переопределите переменную **до** импорта uStatic CSS:

```scss
// В вашем файле переменных
$prefix: "my-";

// Затем импортируйте uStatic CSS
@import 'ustatic-css/src/css/ustatic-index.scss';
```

Теперь все переменные будут иметь префикс `my-`:
- `--my-base-color-primary`
- `--my-base-size-4`

## Использование в коде

Префикс автоматически применяется через функцию `token()`:

```scss
// Функция token() автоматически добавляет префикс
.my-class {
  color: token("base.color.primary"); 
  // Результат: color: var(--u-base-color-primary);
}
```
