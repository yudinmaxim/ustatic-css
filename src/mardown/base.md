# Базовые стили (base)

Модуль содержит CSS reset и базовые стили для всех HTML элементов. Аналог Normalize.css с дополнительными настройками.

## Что включают базовые стили

### Сброс (Reset)

1. **Box-sizing** — `border-box` для всех элементов
2. **Border** — сброс стилей границ
3. **Отступы** — обнуление margin для всех элементов
4. **Список** — удаление стилей списков по умолчанию

### Типографика

1. **Шрифт** — Inter (с системными запасными)
2. **Line-height** — 1.5
3. **Заголовки** — сброс размера и жирности
4. **Ссылки** — наследование цвета, подчёркивание при фокусе
5. **Теги форматирования** — `code`, `kbd`, `samp`, `pre` используют моноширинный шрифт

### Формы

1. **Input, select, textarea** — наследование шрифта
2. **Кнопки** — сброс стилей, `appearance: button`
3. **Placeholder** — серый цвет (gray-400)
4. **Фокус** — outline только для доступных элементов

### Таблицы

1. **border-collapse** — схлопывание границ
2. **text-indent** — сброс отступа для ячеек
3. **border-color** — наследование цвета

### Изображения и медиа

1. **display: block** для img, video, canvas
2. **max-width: 100%** — адаптивность
3. **vertical-align: middle** — выравнивание

### Интерактивность

1. **Курсор pointer** для кнопок и ссылок
2. **Выделение текста** — настраиваемое
3. **Тап-хайлайт** — отключён на iOS

### Состояния

```html
<!-- Отключённый элемент -->
<button disabled>Отключён</button>
<div class="disabled">Отключён</div>

<!-- Скрытый элемент -->
<div hidden>Скрыто</div>
```

## Использование

Базовые стили подключаются автоматически при импорте `ustatic-index.scss`:

```scss
@import 'ustatic-css';
```

Или отдельно:

```scss
@import 'ustatic-css/src/css/modules/base';
```

## Настройка шрифта

Шрифт по умолчанию — Inter. Для изменения:

```scss
// В вашем CSS после импорта base
html {
  font-family: 'Roboto', sans-serif;
}
```

## Настройка цвета ссылок

```scss
// Изменить цвет ссылок
a {
  color: token("base.color.variant.primary");
}
```
