# Введение в uStatic CSS

uStatic CSS — это CSS-библиотека утилитарных классов, вдохновлённая Tailwind CSS и Bootstrap, но с собственной архитектурой на основе дизайн-токенов.

## Основные возможности

### 🎨 Дизайн-токены

Все значения в библиотеке берутся из централизованной системы дизайн-токенов. Это обеспечивает консистентность дизайна и упрощает кастомизацию.

```scss
// Токены преобразуются в CSS переменные
token("base.color.primary") → var(--u-base-color-primary)
token("base.size.4") → var(--u-base-size-4)
```

### 📦 Модульная архитектура

Библиотека разделена на независимые модули, которые можно подключать по отдельности:

| Модуль | Описание |
|--------|----------|
| `base` | Базовые стили и CSS reset |
| `flexbox` | Flexbox раскладка |
| `grid` | CSS Grid раскладка |
| `typography` | Типографика и текст |
| `spacing` | Отступы (margin/padding) |
| `border` | Границы и скругления |
| `bg` | Фоны и цвета |
| `position` | Позиционирование |
| `sizing` | Размеры (width/height) |
| `effects` | Эффекты (opacity, transform) |
| `animations` | Анимации и переходы |
| `interactivity` | Интерактивность (pointer-events, select) |
| `scroll` | Стилизованный скроллбар |
| `cursor` | Виды курсора |
| `outline` | Обводка элементов |
| `hidden` | Скрытие на брейкпоинтах |
| `display` | Display и overflow |
| `align` | Вертикальное выравнивание |
| `filters` | CSS фильтры |

### 🎯 Утилитарные классы

Библиотека предоставляет сотни готовых классов для быстрого стилирования:

```html
<!-- Карточка с тенью -->
<div class="bg-white rounded-lg shadow p-4">
  <h2 class="text-lg font-bold">Заголовок</h2>
  <p class="text-gray-600 mt-2">Описание</p>
</div>

<!-- Flexbox центрирование -->
<div class="flex items-center justify-center h-screen">
  <div>Центрированный контент</div>
</div>

<!-- Кнопка -->
<button class="bg-primary-500 text-white px-4 py-2 rounded hover:bg-primary-600">
  Кнопка
</button>
```

### 🔄 Динамическая загрузка стилей

Для оптимизации размера подключаемых стилей доступна динамическая загрузка только нужных модулей:

```typescript
import { loadStyles } from 'ustatic-css'

// Загрузить только используемые модули
await loadStyles({
  classes: ['flex', 'grid', 'text-center']
})
// Автоматически загрузит: flexbox, display, typography
```

### 🎨 Цветовая палитра

Библиотека включает готовую цветовую палитру:

- **Primary** — основной цвет бренда
- **Secondary** — вторичный цвет
- **Success** — успешные действия
- **Danger** — ошибки и опасные действия
- **Warning** — предупреждения
- **Info** — информационные сообщения
- **Gray** — нейтральные оттенки (50-900)
- **Дополнительные цвета** — red, orange, yellow, green, blue, sky

Каждый цвет имеет оттенки от 50 до 950 для гибкой настройки.

### 📱 Адаптивность

Классы для скрытия/показа элементов на разных брейкпоинтах:

```html
<!-- Скрыто на экранах >= 768px -->
<div class="hidden-md">Только мобильные</div>

<!-- Скрыто на экранах >= 1280px -->
<div class="hidden-lg">Только десктоп</div>
```

### ⚡ CSS переменные

Все значения основаны на CSS переменных, что позволяет легко кастомизировать библиотеку:

```scss
// Переопределение переменных
:root {
  --u-base-color-primary: #3b82f6;
  --u-base-border-radius: 8px;
}
```


## Преимущества

| Преимущество | Описание |
|--------------|----------|
| **Лёгкость** | Минимальный размер, подключение только нужных модулей |
| **Консистентность** | Все значения из дизайн-токенов |
| **Гибкость** | Легкая кастомизация через CSS переменные |
| **Производительность** | Динамическая загрузка, кэширование |
| **TypeScript** | Полная типизация всех утилит |
| **Vue интеграция** | Готовый плагин для Vue 3 |

## Сравнение с аналогами

| Особенность | uStatic CSS | Tailwind CSS | Bootstrap |
|-------------|-------------|--------------|-----------|
| Дизайн-токены | ✅ | ✅ | ⚠️ |
| Динамическая загрузка | ✅ | ❌ | ❌ |
| Vue плагин | ✅ | ❌ | ❌ |
| CSS переменные | ✅ | ✅ | ✅ |
| Размер (minified) | ~50KB | ~300KB | ~200KB |
| Кастомизация | CSS переменные | Конфиг | SCSS переменные |
