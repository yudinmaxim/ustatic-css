# Глоссарий

Словарь терминов uStatic CSS для быстрого понимания документации.

## A

### Align (Выравнивание)
Модуль для вертикального выравнивания элементов с помощью свойства `vertical-align`.

**Классы:** `.align-baseline`, `.align-top`, `.align-middle`, `.align-bottom`

### Animation (Анимация)
CSS-анимации для создания эффектов движения и переходов.

**Классы:** `.blink`, `.animation:spin-*`, `.active:pulse`, `.fade-*`, `.slide-up-*`

### Accent Color (Акцентный цвет)
Цвет, используемый для выделения важных элементов интерфейса.

**Цвета:** Primary, Secondary, Success, Danger, Warning, Info

## B

### Background (Фон)
Модуль для управления фоном элементов: цвета, прозрачность, размытие.

**Классы:** `bg-{color}`, `bg-opacity-*`, `bg-filter-blur-*`

### Border (Граница)
Модуль для управления границами элементов: толщина, цвет, стиль, скругление.

**Классы:** `border`, `border-{width}`, `border-{color}`, `rounded-*`

### Breakpoint (Контрольная точка)
Значение ширины экрана, при котором применяются адаптивные стили.

**Значения:** xs (480px), md (768px), def (1024px), lg (1280px)

## C

### Cursor (Курсор)
Модуль для управления видом курсора мыши.

**Классы:** `.cursor-pointer`, `.cursor-move`, `.cursor-wait`, `.cursor-help`

### Color Palette (Цветовая палитра)
Набор предопределённых цветов для консистентного дизайна.

**Категории:** Primary, Secondary, Success, Danger, Warning, Info, Gray, Red, Orange, Yellow, Green, Blue, Sky

### Container (Контейнер)
Элемент, ограничивающий максимальную ширину контента.

**Класс:** `.max-w-4xl`, `.max-w-6xl`

## D

### Design Token (Дизайн-токен)
Именованное значение в дизайн-системе (цвет, размер, шрифт).

**Формат:** `base.color.primary`, `base.size.4`, `base.border.radius.md`

### Display (Отображение)
Модуль для управления свойством `display` и переполнением `overflow`.

**Классы:** `block`, `inline`, `flex`, `grid`, `overflow-*`

### Divider (Разделитель)
Горизонтальная или вертикальная линия для разделения контента.

**Классы:** `.divider-x`, `.divider-y`

## E

### Effects (Эффекты)
Модуль для визуальных эффектов: прозрачность, трансформации.

**Классы:** `opacity-*`, `rotate-*`, `.required`

### Flexbox (Флексбокс)
Модуль для работы с flexbox раскладкой.

**Классы:** `flex`, `items-*`, `justify-*`, `flex-*`, `grow-*`, `shrink-*`

## F

### Filter (Фильтр)
Модуль для применения CSS фильтров к элементам.

**Классы:** `.grayscale`, `.no-filter`

### Font Weight (Толщина шрифта)
Жирность шрифта от 100 до 900.

**Классы:** `font-thin`, `font-light`, `font-normal`, `font-medium`, `font-bold`, `font-black`

## G

### Gap (Отступ)
Расстояние между элементами во flexbox и grid контейнерах.

**Классы:** `gap-*`, `gap-x-*`, `gap-y-*`

### Grid (Грид)
Модуль для работы с CSS Grid раскладкой.

**Классы:** `grid`, `grid-columns--*`, `grid-rows--*`, `grid-col-span-*`

## H

### Hide (Скрытие)
Модуль для скрытия элементов на разных брейкпоинтах.

**Классы:** `.hidden`, `.hidden-md`, `.hidden-lg`, `.hidden-full`

### Hover (Наведение)
Псевдокласс для стилей при наведении курсора.

**Классы:** `hover:bg-*`, `hover:text-*`, `hover:opacity-*`

## I

### Interactivity (Интерактивность)
Модуль для управления интерактивным поведением элементов.

**Классы:** `pointer-events-*`, `select-*`

### Outline (Контур)
Модуль для управления внешней обводкой элементов.

**Классы:** `outline-none`, `outline-*`, `outline-{color}`, `outline-offset-*`

## M

### Margin (Внешний отступ)
Расстояние снаружи элемента.

**Классы:** `m-*`, `mx-*`, `my-*`, `mt-*`, `mr-*`, `mb-*`, `ml-*`

### Max-width (Максимальная ширина)
Ограничение максимальной ширины элемента.

**Классы:** `max-w-xs`, `max-w-sm`, `max-w-md`, `max-w-lg`, `max-w-xl`

## O

### Opacity (Прозрачность)
Степень прозрачности элемента от 0% до 100%.

**Классы:** `opacity-0`, `opacity-50`, `opacity-100`

### Overflow (Переполнение)
Управление поведением контента, выходящего за границы элемента.

**Классы:** `overflow-hidden`, `overflow-scroll`, `overflow-auto`

## P

### Padding (Внутренний отступ)
Расстояние внутри элемента между контентом и границей.

**Классы:** `p-*`, `px-*`, `py-*`, `pt-*`, `pr-*`, `pb-*`, `pl-*`

### Position (Позиционирование)
Модуль для управления позиционированием элементов.

**Классы:** `relative`, `absolute`, `fixed`, `sticky`, `top-*`, `left-*`, `z-*`

### Primary (Основной)
Основной цвет бренда, используемый для акцентных элементов.

**Оттенки:** `primary-50` ... `primary-950`

## R

### Rounded (Скругление)
Модуль для скругления углов элементов.

**Классы:** `rounded-none`, `rounded-sm`, `rounded-lg`, `rounded-full`

## S

### Scroll (Прокрутка)
Модуль для стилизации полосы прокрутки.

**Классы:** `.z-scroll`, `.z-scroll--thin`, `.z-scroll--hovered`

### Sizing (Размеры)
Модуль для управления шириной и высотой элементов.

**Классы:** `w-*`, `h-*`, `min-w-*`, `max-h-*`, `size-*`

### Spacing (Отступы)
Модуль для управления внешними и внутренними отступами.

**Классы:** `m-*`, `p-*`

## T

### Text (Текст)
Модуль типографики для управления текстом.

**Классы:** `text-*`, `font-*`, `text-{color}`, `text-center`

### Token (Токен)
См. Design Token

### Transition (Переход)
Плавный переход между состояниями элемента.

**Классы:** `.fade-*`, `.slide-up-*`, `.scale-*`

### Typography (Типографика)
Модуль для управления текстом: размер, цвет, выравнивание, толщина.

**Классы:** `text-size-*`, `font-weight-*`, `text-align-*`

## U

### User Select (Выделение)
Управление возможностью выделения текста.

**Классы:** `select-none`, `select-auto`, `select-all`

## Z

### Z-index (Слой)
Порядок наложения элементов по вертикали.

**Классы:** `z-0` ... `z-100`, `z-i-modal`, `z-i-menu`, `z-i-notice`
